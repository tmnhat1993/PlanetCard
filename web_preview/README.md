# Planet Deckbuilder — HTML UI Lab

Interactive wireframe preview for the STONE + PLANT vertical slice.

## Run locally

Requires Node.js 20.19 or newer.

```bash
pnpm install
pnpm dev
```

Open the Local URL printed by the server. Use the top rail, Previous/Next, or
`Cmd/Ctrl + K` to move between the 15 wireframe screens.

## Current scope

- Overview/system map.
- Combat and result.
- Deck Builder and collection.
- Home, production, shipyard and research.
- World map, Intel and expedition.
- Trade, booster and mastery.

The preview models presentation and navigation only. Gameplay results remain
fixture-driven and will be implemented in Godot domain systems.
