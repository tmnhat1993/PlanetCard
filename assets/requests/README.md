# Asset Requests

Asset request mô tả nhu cầu gameplay trước khi tạo PixelLab manifest.

Lifecycle:

`BRIEF → GENERATING → GENERATED → REVIEW → REVISION/APPROVED → IMPORTED → IN_GAME_QA → LOCKED`

Copy `_template.json`, đổi asset/version và điền acceptance checklist. Prompt cuối vẫn nằm trong manifest; request không thay thế Global/Faction/Asset art briefs.
