# 01 — Core Loop

## Macro loop

Home Planet
→ collect production
→ queue processing
→ choose ship upgrade
→ configure relics
→ build deck
→ inspect planet intel
→ launch expedition
→ clear stage(s)
→ gain salvage / mastery / unlock
→ return home
→ production advances
→ trade / research / upgrade
→ repeat

## Planet conquest loop

1. Enter planet.
2. Learn its main mechanic.
3. Stage 2 introduces interaction/counter.
4. Stage 3 combines mechanics.
5. Stage 4 = elite exam.
6. Stage 5 = boss exam.
7. Defeat boss.
8. Unlock Trade License.
9. Export home products.
10. Earn local currency.
11. Buy faction booster packs.
12. Increase Planet Mastery.
13. Add new faction cards into hybrid deck.
14. Revisit challenge/advanced content.

## Economy clock

Không dùng realtime waiting ở MVP.

Một `Expedition Step` = một production cycle.

Ví dụ:
- Queue 5 Alloy.
- Clear stage 1 → +1 cycle.
- Clear stage 2 → +1 cycle.
- Return home → production result được claim.

Điều này tạo cảm giác hành tinh vẫn hoạt động trong lúc player đi chiến đấu mà không biến game thành idle timer.

## Failure

Thua expedition:
- quay về homeworld,
- mất một phần unbanked salvage,
- không mất permanent card/ship,
- giữ knowledge/unlock hợp lý.

Mục tiêu: khuyến khích rebuild, không punish khiến player farm lại từ đầu.
