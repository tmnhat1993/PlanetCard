# 05 — Starter Planet Content

## Universal 5-stage teaching structure

1. Introduce
2. Counter / interaction
3. Combination
4. Elite exam
5. Boss exam

## PLANT campaign

### Stage 1 — Thornlings
3 enemies nhỏ.
Teaches: Poison + target priority cơ bản.

### Stage 2 — Vine Guard
Formation:
- Spore Caster
- Vine Guard

Guard protects; Caster applies Poison.
Teaches: Support/Tank priority.

### Stage 3 — Parasite Bloom
Adds Spore Junk into player deck.
Teaches: deck disruption.

### Stage 4 — Rootkeeper
- Root cards,
- Heal allies,
- Summon.
Teaches: control + sustain + summon.

### Stage 5 — Mycelial Queen

Phase 1: summon buds.  
Phase 2: Poison + Root.  
Phase 3: buds Bloom; each living Bloom powers Queen.

Decision:
- rush boss,
- or clear summons.

## STONE encounter set

### Stage 1 — Pebble Warriors
Armor intro.

### Stage 2 — Crystal Guard
Protect mechanic.

### Stage 3 — Excavator
Adds Rubble Junk.

### Stage 4 — Basalt Sentinel
Counter + high durability.

### Stage 5 — Lithic Sovereign
Phase 1: Armor wall.
Phase 2: Fracture player.
Phase 3: Crystal minions + heavy cannon.

## Advanced faction concepts

### LIGHT
Charge / Prism / Reflect.
Resource: Photon Crystal.

### DARK
Curse / Sacrifice / Corruption.
Resource: Void Matter.

### TECH
Drone / Overheat / Hack.
Resource: Circuit / Processor.

### MYTH
Pact / Deity / Transformation.
Resource: Essence / Relic Fragment.

Mỗi advanced planet có thể có 10 stages, nhưng dùng cùng encounter framework.
