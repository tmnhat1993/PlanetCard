# PHASE 7 — STONE Playable Slice

## Objective

Hoàn thành loop nhỏ STONE trước khi thêm PLANT trade/pack complexity.

## Scope

- STONE Home.
- STONE resource chain.
- 3–5 STONE encounters.
- One elite/boss milestone phù hợp content readiness.
- STONE deck/relics.
- Research one meaningful card/unlock.
- Cargo/Hull upgrade choice.
- Expedition return và claim.
- Save/load/autosave.

## Player journey

`Produce → Upgrade/Research → Build Deck → Expedition → Return → Claim → Rebuild`

## Exit gate

- Economy tạo ít nhất một decision combat rõ ràng.
- Cargo upgrade mở build khác, không chỉ tăng số vô nghĩa.
- Player hiểu production advance bằng expedition cycle.
- New player hoàn thành journey không dùng debug controls.
- Art/UI đủ coherent để external playtest, chưa cần full polish.
